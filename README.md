# TIK DZ — Live Stream Key & OBS Studio Manager

تطبيق ويب بواجهة زجاجية داكنة (Liquid Glass UI) لإدارة مفاتيح البث المباشر وإعدادات البث المتوافقة مع **OBS Studio** و **Prism Live**.

## المميزات (Features)
- **واجهة زجاجية داكنة (Dark Liquid Glass)**: تصميم مستوحى من iOS 27 و ColorOS 17 بألوان الأسود الرمادي والأحمر مع أيقونات ثلاثية الأبعاد.
- **توليد وإدارة مفاتيح RTMP**: معاينة توليد المفتاح، الإظهار/الإخفاء، التدوير، والنسخ السريع لرابط الخادم والمفتاح.
- **تحكم متكامل في جودة البث**:
  - اتجاه البث: عمودي `9:16` أو أفقي `16:9` (مع دعم البث المزدوج).
  - الدقة: `720p` / `1080p` / `2K` / `4K`.
  - معدل الإطارات: `30` / `60` / `90` / `120 FPS`.
  - معدل البت (Bitrate) مع زر الضبط التلقائي، واختيار المُرمّز (`H.264 NVENC`, `H.265`, `x264`, `AV1`)، وتصدير ملف إعدادات **OBS JSON**.
- **جاهز لربط TikTok OAuth 2.0**: نافذة إعدادات المطور لإدخال `Client Key` و `Redirect URI` ورابط الخادم الوسيط (Backend).

## ملاحظة تقنية حول TikTok API
واجهة [TikTok Login Kit](https://developers.tiktok.com/doc/login-kit-overview) الرسمية توفر صلاحيات قراءة بيانات الملف الشخصي الأساسية ولا تمنح واجهة عامة لتوليد مفاتيح RTMP حقيقية؛ لإصدار مفاتيح بث فعلية عبر التطبيق ستحتاج إلى خادم وسيط (Backend) واعتماد شريك رسمي من TikTok LIVE.

## التشغيل المحلي
افتح الملف `index.html` مباشرة في أي متصفح حديث، أو شغّل خادماً محلياً:
```bash
python3 -m http.server 8080
```
